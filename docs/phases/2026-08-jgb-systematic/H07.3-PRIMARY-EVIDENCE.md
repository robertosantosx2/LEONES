## Objetivo

Recoger evidencia directamente de las fuentes primarias del modelo y asociarla a una identidad concreta. El índice JGB exige conservar evidencia y confianza junto a la clase, y mantiene separadas las cinco dimensiones: Access, Model control, Data control, Autonomy y Trust. fileciteturn121file0L2-L2

## Registro mínimo de evidencia

Cada comprobación debe poder responder:

| Campo | Significado |
|---|---|
| `model_id` | Identidad canónica del modelo |
| `variant` | Variante exacta cuando aplique |
| `dimension` | Dimensión JGB evaluada |
| `claim` | Afirmación que se quiere comprobar |
| `source_url` | Fuente primaria |
| `source_title` | Identificación legible de la fuente |
| `checked_at` | Fecha/hora de comprobación |
| `evidence_excerpt` | Extracto breve o referencia precisa |
| `status` | `verified`, `provisional`, `unknown` o `disputed` |
| `confidence` | Confianza de la evaluación |

## Fuentes prioritarias

Orden de preferencia:

1. documentación oficial del modelo;
2. repositorio oficial del modelo o de su organización;
3. licencia oficial y textos legales asociados;
4. documentación oficial de entrenamiento/inferencia;
5. dataset o documentación oficial del dataset, cuando sea necesario para la dimensión evaluada.

Una fuente secundaria puede servir para descubrir una pista, pero no debe convertirse automáticamente en evidencia primaria.

## Qué se verifica

### Access

Hay que comprobar qué acceso real existe al modelo y bajo qué condiciones.

### Model control

Hay que comprobar qué se puede modificar, estudiar, fine-tunear o redistribuir y qué restricciones existen.

### Data control

Hay que comprobar el control sobre prompts, resultados y datos en el escenario relevante.

### Autonomy

Hay que comprobar la dependencia respecto al proveedor y la posibilidad de operar sin servicios externos cuando esa afirmación sea parte de la clasificación.

### Trust

Hay que comprobar si existe información suficiente para estudiar y asegurar el comportamiento del sistema. Para clases superiores, el índice JGB exige evidencia específica sobre software, entrenamiento, modelo y, en el nivel reproducible, datos de entrenamiento. fileciteturn121file0L2-L2

## Regla de prudencia

No se rellenará una dimensión porque otra dimensión sea positiva.

Ejemplo:

```text
pesos disponibles
      ≠
open source
      ≠
reproducible
```

Tampoco:

```text
self-hostable
      ≠
JGB nivel 5
```

El propio índice separa explícitamente self-hostability de apertura/libertad. fileciteturn121file0L2-L2
