## Qué valida H07.6

La validación final comprueba que el circuito conserva las reglas del proyecto desde el candidato Atlas hasta el dato que puede consultar el Router:

```text
CANDIDATO
   ↓
AUDITORÍA
   ↓
EVIDENCIA PRIMARIA
   ↓
5 DIMENSIONES JGB
   ↓
CLASE
   ↓
CONFIANZA + FUENTES
   ↓
ATLAS / ROUTER
```

## Lista de comprobación

- [x] JGB se trata como conocimiento independiente.
- [x] Las dimensiones Access, Model control, Data control, Autonomy y Trust permanecen separadas.
- [x] `verified`, `provisional`, `unknown` y `disputed` se conservan como estados distintos.
- [x] La ausencia de evidencia no se convierte en una afirmación positiva.
- [x] JGB no se deduce de benchmarks.
- [x] JGB no se deduce de rendimiento.
- [x] JGB no se deduce de precio.
- [x] JGB no se deduce de self-hostability.
- [x] JGB no sustituye CABE/RULA.
- [x] JGB no sustituye `fit_score`.
- [x] Las fuentes y la fecha de comprobación forman parte de la trazabilidad.
- [x] El Router debe devolver `unknown` cuando no dispone de evidencia adecuada.
- [x] La integración no autoriza a inventar clases para los candidatos sin verificar.

El contrato de H07 está cerrado a nivel de infraestructura y proceso. El README de la fase mantiene correctamente H07 como **infraestructura operativa con clasificación factual pendiente de evidencia primaria**, que es el estado real del proyecto. fileciteturn124file0L2-L2

Por tanto, no se cambia H07 a `🟢 CERRADA` todavía.

## Qué queda realmente pendiente

La tarea pendiente ya no es diseñar el mecanismo, sino **obtener y registrar evidencia primaria real para los candidatos** y, con ella, producir clasificaciones verificables.

Ese trabajo puede hacerse progresivamente. Un candidato sin evidencia suficiente permanece `unknown` y no bloquea la calidad del resto del Atlas.

## Regla de no concurrencia

Cualquier workflow futuro que escriba en el catálogo o artefactos canónicos debe respetar la regla global de no concurrencia de LEONES. La validación JGB no crea una excepción a esa regla.

## Criterio de cierre global

H07 solo pasará a 🟢 cuando las clasificaciones que se publiquen como verificadas dispongan de evidencia suficiente y reproducible y una auditoría confirme que no se han inferido desde propiedades ajenas al marco JGB.
