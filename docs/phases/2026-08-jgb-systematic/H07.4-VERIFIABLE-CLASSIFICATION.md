## Principio

La clasificación JGB no es una puntuación de calidad ni de rendimiento. El índice del proyecto evalúa cinco dimensiones independientes: **Access, Model control, Data control, Autonomy y Trust**, y deriva de ellas las clases 0–5. fileciteturn122file0L2-L2

## Regla de clasificación

Un modelo solo puede recibir una clase cuando la evidencia disponible permite sostener las dimensiones exigidas por esa clase. La clase superior no se obtiene por "parecido", reputación, popularidad, benchmark o capacidad de ejecución local.

```text
0  Behind-app model
1  Directly accessible model
2  Available weights model
3  Open weight model
4  Open source model
5  Reproducible (libre) model
```

Las condiciones de cada nivel son las definidas por el índice JGB del proyecto. En particular, Open source añade software open source para entrenamiento/inferencia y descripción detallada del entrenamiento; Reproducible añade toda la información sobre el modelo y disponibilidad del dataset de entrenamiento. fileciteturn122file0L2-L2

## Método reproducible

Para cada modelo:

1. identificar el modelo y variante exactos;
2. recopilar evidencias por dimensión;
3. evaluar cada dimensión independientemente;
4. asignar `verified`, `provisional`, `unknown` o `disputed` a la evidencia;
5. registrar la confianza;
6. aplicar las condiciones del nivel JGB;
7. conservar la evidencia que justifica la clase;
8. si falta una condición necesaria, no elevar la clase por inferencia.

## Regla conservadora

La ausencia de evidencia no demuestra que una condición sea falsa, pero tampoco permite declararla cierta. Por ello, cuando una condición necesaria para una clase no puede verificarse, el resultado debe permanecer **unknown/provisional** y no promocionarse como `verified`.

Esta precaución es especialmente importante porque la propia fuente reconoce dificultades para determinar la categoría de un modelo y la necesidad de verificar que las declaraciones sean verdaderas. fileciteturn122file0L2-L2

## Separaciones obligatorias

### JGB ≠ rendimiento

Un modelo rápido no obtiene una clase JGB mayor.

### JGB ≠ calidad

Benchmarks como GPQA o coding no determinan JGB.

### JGB ≠ self-hostability

Poder ejecutar un modelo localmente es una propiedad técnica distinta. El índice mantiene expresamente separadas apertura/libertad y self-hostability. fileciteturn122file0L2-L2

### JGB ≠ score

La clase no se sustituye por un número agregado de calidad. El Atlas conserva las dimensiones y la evidencia por separado.
