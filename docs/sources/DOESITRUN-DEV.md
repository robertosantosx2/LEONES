# doesitrun.dev

## Identidad
- Fuente primaria: https://doesitrun.dev/
- Capa: compatibilidad hardware/modelo.
- Estado LEONES: `research-candidate`.

## Qué es
Calculadora web para comprobar si determinados modelos locales pueden ejecutarse con un hardware dado.

## Qué aporta
Es otra señal independiente del problema “fit”, útil para comparar supuestos y detectar falsos positivos/negativos de los estimadores.

## Evidencia
La web es la fuente primaria de sus resultados; estos se mantienen como información externa.

## Estimación
Compatibilidad y requisitos de memoria/rendimiento son estimaciones del servicio.

## Medición LEONES
Pendiente.

## Valor para LEONES
Útil como fuente de prospección y cross-validation, no como autoridad de recomendación.
