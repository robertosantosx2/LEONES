# Integraciones IA locales

LEONES integra dos perfiles complementarios:

- **Servidor de Stacks IA:** ODS.
- **Asistente personal IA:** Magnitude.

## Principio común

`hardware observado → instalación/configuración → recomendación → benchmark LEONES → resultado medido → Atlas`

Las recomendaciones de ODS/Magnitude nunca sustituyen una medición independiente de LEONES.

## Privacidad

La instalación no implica telemetría. Los registros compartidos deben limitarse a metadatos técnicos consentidos y nunca incluir prompts, conversaciones, documentos, secretos, tokens, API keys o contenido RAG.
