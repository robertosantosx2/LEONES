Local inference engines for ODS

Technical comparative analysis oriented to ODS. The question is not which is “best” in the abstract, but which inference problem each engine solves and what role it should play in an architecture that discovers the best real configuration for the available hardware (Inference Configuration Discovery).

Updated: 2026-10-06 Local inference MoE / offload / streaming Speculative / parallel decode OpenAI-compatible API ODS
Main thesis: they are not equivalent alternatives. cafe-llama.cpp (and the ggml/llama.cpp ecosystem) is the generalist platform and baseline; Strata is an extreme specialization for huge MoE models on consumer hardware (expert cache + RAM/CPU + SSD + MTP); TensorFold is a decode accelerator (parallel/speculative) focused on Apple Silicon and CUDA; MoE-Infinity, ramvamp, Edge0, BigMoeOnEdge, FrankenMoE-CUDA, moe-stream and related projects attack the same “fit MoE models that do not fit” problem with different memory hierarchies and expert prediction; FATE / HybriMoE / HOBBIT contribute composable capabilities (prediction, CPU/GPU scheduling, adaptive cache). ODS should model them as Inference Engine Candidates + execution strategies, not as a binary selector.
