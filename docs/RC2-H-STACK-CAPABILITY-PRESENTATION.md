# RC2-H — ODS / Magnitude capability presentation

**Estado:** 🟢 Contrato fijado (feedback beta 2026-09-02)

Antes de elegir stack, LEONES presenta capacidades declaradas. El menú de elección **incluye una descripción corta**, no solo el nombre.

```text
ELIGE TU STACK
┌──────────────────────────────────────────────────────────┐
│  [1] ODS — stack local de inferencia                     │
│  [2] Magnitude — agente/asistente local                  │
└──────────────────────────────────────────────────────────┘
```

## ODS

Stack local de inferencia; preparación/validación del plan; integración con ejecución local; medición vía pipeline común cuando proceda. El adaptador LEONES no instala ODS por sí mismo.

## Magnitude

Integración orientada a agente/asistente; preparación de metadatos; ejecución separada; reutilización de benchmark/evidencia comunes.

## Honestidad

Solo se muestran capacidades respaldadas por contrato o evidencia. Pendiente/experimental se etiqueta como tal. Elegir stack no autoriza instalación ni benchmark.
