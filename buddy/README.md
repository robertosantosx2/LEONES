# 🦁 LEONES · Buddy

Buddy conserva conocimiento y contexto útil del usuario de forma independiente del modelo concreto.

## Contrato v0.1

- preferencias de ejecución;
- decisiones y configuraciones aprobadas;
- contexto de proyectos;
- procedimientos reutilizables;
- referencias a evidencia.

Buddy no debe almacenar secretos ni sustituir la evidencia de Atlas. Su contenido se trata como contexto, no como verdad verificada.

## Flujo

`usuario → Buddy → Task Intelligence → Router`

La persistencia y sincronización quedan pendientes de una implementación local explícita.
