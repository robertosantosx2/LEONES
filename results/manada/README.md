# Manada — Resultados

Este directorio almacena los informes técnicos que los usuarios deciden compartir voluntariamente con LEONES.

## Cómo aportar

```bash
python3 scripts/leones-manada-report.py --model ~/models/Qwen3-8B-Q4_K_M.gguf --publish
```

El informe se revisa antes de publicarse y no debe contener datos personales ni identificadores de la máquina.

## Estructura

```text
results/manada/
├── README.md
├── 20260810-231500-H1.md
├── 20260811-091200-H2.md
└── ...
```

Los resultados de Evaluación B01–B05 pueden completarse en el informe antes de compartirlo.
