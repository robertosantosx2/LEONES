Qué es LEONES

LEONES es una plataforma autónoma de IA local. Su objetivo no es ser una interfaz para un único runtime: debe seleccionar y ejecutar la combinación adecuada de modelo, cuantización, backend y hardware para cada tarea.

Unsloth Desktop no es una dependencia principal. Unsloth, llama.cpp, KTransformers, Ollama y otros son adaptadores posibles.

Componentes congelados

  • Leones Atlas: conocimiento estructurado.
  • Leones Router: decisión de modelo + cuantización + backend + dispositivo.
  • Leones Agents: planificación, herramientas, memoria y workflows.
  • Leones Runtime: ejecución local y adaptadores.
  • Leones Quant: cuantización y evaluación de compromisos.
  • Leones Fine-Tuning: adaptación del modelo, incluyendo LoRA/QLoRA.
  • Benchmark & Evaluation: evidencia reproducible que retroalimenta Atlas y Router.

Primera implementación

La rama architecture/leones-0.2 contiene ya contratos y primeras implementaciones para Atlas, Router, Runtime, Agents, Quant, Fine-Tuning, Evaluation, Hardware Intelligence y Task Intelligence.

El primer backend de referencia es llama.cpp, pero la arquitectura no depende de él.

Regla de ingeniería

Scripts sencillos que hagan las menores cosas posibles y estén muy documentados.

hardware → model → infer → LOTB → report → publish → stats

Cada paso tendrá una responsabilidad clara. No se construirá un orquestador monolítico que mezcle descubrimiento, descarga, inferencia, benchmark y publicación.
