LEONES · SISTEMA VISUAL

Diagramas que explican, no decoran

Los mapas y esquemas se conservan en ASCII para que la arquitectura sea legible, versionable, accesible y verificable directamente desde el repositorio.

Fuente canónica: estos esquemas recuperan la representación textual de la documentación de arquitectura de LEONES. No se sustituyen por imágenes decorativas ni por una interpretación gráfica diferente.
01 · Pipeline

Pipeline completo

USER / MACHINE
      │
      ▼
┌───────────────┐
│ leones-hardware│  identify machine
└───────┬───────┘
        ▼
┌───────────────┐
│ leones-model   │  identify model

        ▼

        ▼

Este es el recorrido operativo: identificar máquina y modelo, medir inferencia, evaluar tareas agentivas, generar el resultado y validarlo antes de publicar.

La documentación define estas capas como sustituibles donde sea práctico: el conocimiento y contexto no deben quedar acoplados a un modelo, backend o hardware concreto.

03 · Discovery

De descubrimiento a recomendación

discover → inspect → classify → test → recommend → incorporate

La prospección descubre proyectos; la inspección, clasificación y prueba aportan evidencia antes de recomendar o incorporar. Encontrar un proyecto no significa que LEONES lo respalde.

04 · Evidencia

Estados de un resultado

reported → reproducible → verified
                 │
                 └── rejected

Un resultado reportado no se presenta como verificado. La documentación conserva explícitamente la diferencia entre estados.
