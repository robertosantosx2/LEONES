La licencia de Unsplash permite descargar, copiar, modificar, distribuir y utilizar las imágenes gratuitamente, incluso con fines comerciales, sin exigir atribución; aun así, LEONES mantiene la atribución cuando resulta razonable.

La licencia vigente debe consultarse siempre en:

https://unsplash.com/es/licencia

## Criterio de diseño

La fotografía no sustituye la información técnica. Se utiliza para:

1. Dar a LEONES una identidad visual reconocible.
2. Evocar la idea de **manada**, cooperación y ecosistema.
3. Introducir profundidad visual en portadas y separadores.
4. Servir como materia prima para marcas visuales fotográficas.
5. Mantener el contenido técnico legible mediante capas oscuras, contraste y transparencias.

## Nota

No se utilizan imágenes marcadas como **Unsplash+** para esta identidad visual. Unsplash+ tiene condiciones adicionales, entre ellas restricciones específicas relacionadas con IA y otras formas de uso.
