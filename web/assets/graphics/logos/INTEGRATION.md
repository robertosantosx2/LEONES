# Integración visual

Los logos funcionales deben aparecer en las secciones que representan, manteniendo el león principal como identidad común.

Rutas desde las páginas de `web/`: `assets/graphics/logos/<fichero>.svg`.

Se recomienda un tamaño de 44–72 px en navegación y 80–128 px en cabeceras o tarjetas. El símbolo funcional se diseñó grande para conservar significado incluso en tamaños reducidos.
