LEONES identifica qué piezas de la pila pueden ayudarte a conseguir una experiencia local más útil y aprende de la evidencia que encuentra.

Ahora también puedes enseñarle algo a LEONES

Si conoces un modelo, runtime, herramienta, benchmark, proyecto, dataset o idea que debamos estudiar, envíanoslo. La propuesta entra como descubrimiento externo y pasa por un proceso de verificación antes de integrarse.

Recomendar algo a LEONES
CASO 1 · DEMO

Más memoria de contexto con una capa de conocimiento controlada

Situación: una pila puede producir buenos resultados, pero pierde coherencia cuando aumenta el número de documentos y decisiones que debe manejar el agente.

Recomendación: incorporar una capa de conocimiento controlado mediante Buddy, separando el conocimiento persistente del modelo que genera los tokens.

Por qué fue relevante: la mejora no depende de cambiar inmediatamente de modelo. Permite conservar el conocimiento al cambiar modelo, backend, harness o hardware.
CASO 2 · DEMO

Cambiar backend para mejorar el rendimiento local

Situación: una máquina cumple por capacidad de modelo, pero las tareas agentivas tardan demasiado.

Recomendación: probar otro backend de inferencia compatible con el mismo formato/modelo antes de sustituir el hardware.

Por qué fue relevante: una pieza distinta de la pila puede mejorar el tiempo de respuesta sin modificar el conocimiento ni obligar al usuario a comprar otra máquina.
CASO 3 · DEMO

Optimizar la pila para una máquina sin GPU

Situación: CPU y RAM suficientes, pero sin acelerador gráfico.

Recomendación: priorizar modelos cuantizados y un backend CPU eficiente cuando la tarea no necesita mayor capacidad.

Por qué fue relevante: LEONES busca la combinación de piezas que permita terminar tareas, no maximizar artificialmente el tamaño del modelo.

Cómo se generan y validan

manada_leones aporta características y medidas. Prospector descubre nuevas piezas. Las recomendaciones de usuarios añaden otra fuente de descubrimiento. Después se comprueban identidad, procedencia y evidencia; si procede, se reproduce la afirmación. Solo entonces puede pasar a Atlas o modificar una recomendación del sistema.
