manada_leones

La experiencia acumulada de ejecuciones locales puede alimentar el conocimiento distribuido de LEONES, sin convertir una estimación externa en una medición propia.

máquina → diagnóstico → result.json → report.md → GitHub → estadísticas → web

Cómo se recomienda

Las recomendaciones deben considerar hardware, sistema operativo, runtime, backend, modelo, cuantización, harness, skills y evidencia disponible. Cuando la evidencia no es suficiente, LEONES debe indicarlo.

Transparencia

Los datos externos se distinguen de los resultados medidos por LEONES. Una recomendación puede ser útil sin convertirse por ello en una validación oficial.
