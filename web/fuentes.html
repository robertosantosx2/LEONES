Model Sources

La capa que separa el origen de un modelo de su descarga, registro y ejecución.

Flujo

Model Source → Downloader → Atlas → Runtime

Descarga mínima

Una fuente contiene una URL HTTP/HTTPS y, cuando está disponible, el SHA-256 esperado. El downloader descarga exactamente el archivo indicado y elimina el archivo si la comprobación de SHA-256 falla.

Qué no hace

  • no elige modelos;
  • no verifica automáticamente licencias;
  • no ejecuta modelos;
  • no modifica el catálogo de Atlas.

Principio

Primero una operación elemental y verificable. Las integraciones con catálogos externos se añadirán después, sin convertir el downloader en un componente monolítico.
