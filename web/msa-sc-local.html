MSA Run local

Ficha de conocimiento de LEONES para Model Spend Arena — sección de ejecución local (msa.millaguie.net/#local).

VERIFICADA · 2026-09-02

Qué es

Model Spend Arena (MSA) es un mapa público de coste y calidad de modelos de coding. La sección Run local publica un catálogo de modelos open-weight que caben por presupuesto de VRAM, con tamaños GGUF reales, contexto residual por cuantización y mediciones first-party de BigCodeBench-Hard donde existen.

Nota de ancla: la referencia histórica #sc-local no aparece en el sitio. La sección real es #local / #localpick (“Run local” / “What to run locally”).

Verificación

El 23/08/2026 el acceso primario falló y la ficha quedó UNRESOLVED sin inventar contenido. El 02/09/2026 el sitio respondió y se confirmó el contenido de Run local (actualización del sitio ~2026-08-30).

  • Tiers de VRAM: ≤8, ≤12, ≤16, ≤24, ≤32 GB.
  • Pesos en bytes GGUF medidos; no solo “VRAM de marketing”.
  • Ranking mixto: % BCB (MSA) e índice de coding de Artificial Analysis, escalas no comparables.
  • Runtime de referencia: llama.cpp / llama-server; tok/s desde GPUs de escritorio.
  • Protocolo BCB-Hard oficial (148 problemas); mediciones previas al 23/08 con 121 problemas retiradas.

Qué aporta a LEONES

  • Prospección de candidatos open-weight orientados a coding local.
  • Evidencia externa first-party de calidad coding bajo protocolo documentado.
  • Criterios de selector: VRAM real (pesos + KV), cuantización vs contexto, “cabe ≠ útil”.
  • Metodología: retirar números no comparables en lugar de convertirlos.
MSA Run local → descubrimiento → procedencia → quality gate → candidate → runtime-selection.v1 → benchmark LEONES → evidence

Contrato de evidencia

reported = publicado por MSA · observed = confirmado por LEONES en la URL · verified = comprobado en fecha · measured = solo ejecución LEONES en su hardware.

Una cifra de MSA no es medición LEONES ni recomendación automática.
