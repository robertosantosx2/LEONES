Arrancar LEONES

RC3 cerrada. Camino actual de producto: sonda LEONES, FitLLM como recomendador opcional, elección humana de modelo y stack.

0 · Qué es canónico

RC4 redefine la recomendación de modelo. RC3 permanece cerrada como fase.

Regla: LEONES descubre el hardware. FitLLM puede recomendar. El usuario elige. Magnitude u ODS ejecutan. LEONES verifica, mide y sentencia.

1 · Requisitos

  • Python 3 y Git.
  • No hace falta FitLLM para arrancar.
  • Hermes y OMH son opcionales (agente/ops); no seleccionan modelo.
  • ODS puede requerir Docker; Magnitude su propio runtime.
git clone https://github.com/robertosantosx2/LEONES.git
cd LEONES
./install.sh

2 · Sonda física

python3 scripts/hardware_profile.py
python3 scripts/rc3_hardware_discovery.py

3 · Recomendación y elección

Si FitLLM está instalado, puede proponer candidatos (ESTIMATED). Si no, eliges modelo a mano. Luego un stack: Magnitude u ODS.

Tras instalar el stack, el flujo puede ofrecer desinstalar FitLLM (opt-in, nunca en silencio).

4 · Medición

Suite Leo001…Leo010 cuando haya runtime, consentimiento y ejecución real. Sin eso: no MEASURED.
