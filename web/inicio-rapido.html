Arrancar LEONES en Ubuntu

Camino canónico actual: sonda física LEONES, ecosistema Hermes/OMH, elección explícita de Magnitude u ODS, verificación y medición solo tras ejecución real.

0 · Qué es canónico

RC3, no RC2

RC3 es el camino canónico. RC2 queda como línea histórica. LLMFit/FitLLM no es dependencia de arranque ni participa en la selección RC3.

Regla de autoridad: LEONES descubre el hardware. OMH organiza. El usuario elige. Magnitude u ODS preparan/ejecutan. LEONES verifica, mide y sentencia.
1 · Requisitos

Antes de instalar

  • Ubuntu (u otro Linux) con Python 3 y Git.
  • Espacio en disco y, si usas ODS, Docker cuando el stack lo requiera.
  • No hace falta LLMFit para arrancar RC3.
git clone https://github.com/robertosantosx2/LEONES.git
cd LEONES
./install.sh   # bootstrap LEONES + Hermes/OMH según el instalador actual

Comprobaciones independientes del ecosistema:

hermes doctor
omh doctor
2 · Sonda física

La autoridad del hardware es LEONES

La única sonda física canónica es scripts/hardware_profile.py. Emite hechos observados (CPU, RAM, GPU PCI…). No inventa VRAM ni measured_tps.

python3 scripts/hardware_profile.py
python3 scripts/rc3_hardware_discovery.py   # hardware-profile.v1
python3 scripts/rc3_release_gate.py         # contratos estáticos; físico NOT CLAIMED
3 · Elección

Modelo y un solo stack

Tras el perfil y los candidatos, tú eliges modelo/configuración y exactamente un camino:

Magnitude

Perfilado, tuning y ejecución por sus interfaces canónicas. LEONES verifica lo instalado antes de medir.

ODS

Instalación y stack local por sus interfaces canónicas. LEONES no duplica el instalador ODS.

Consentir ≠ instalar ≠ verificar ≠ autorizar benchmark.

4 · Regla de oro

No confundas estados

ESTIMATED

Orientación externa o de ranking. No es medición local.

OBSERVED

Hecho visto en el host (doctor, status, sonda). No autoriza MEASURED.

MEASURED

Solo tras ejecución real registrada por el camino LEONES.

UNKNOWN

Si no se puede comprobar, permanece desconocido.

ESTIMATED ≠ MEASURED. OBSERVED ≠ VALIDATED.
