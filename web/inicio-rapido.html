0 · Dependencias

Antes de clonar: LLMFit

LLMFit es una dependencia dura de LEONES. Detecta tu hardware y propone candidatos de modelo. LEONES no lo instala ni lo sustituye: debe estar disponible como comando llmfit en el PATH.

Sus cifras de velocidad son ESTIMATED, no mediciones LEONES.

En Linux / Fedora (recomendado, sin sudo):

curl -fsSL https://llmfit.axjns.dev/install.sh | sh -s -- --local
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
command -v llmfit

Alternativas: brew install llmfit o uv tool install -U llmfit.

Documentación oficial de LLMFit: https://www.llmfit.org/ · GitHub AlexsJones/llmfit.

1 · Arranque

De cero a LEONES

En una terminal Linux, el camino mínimo del beta tester es:

git clone https://github.com/robertosantosx2/LEONES.git
cd LEONES
./install.sh
./leones

No necesitas lanzar el script interno directamente. ./leones es el lanzador único del wizard RC2. La instalación mínima comprueba Git, Python y LLMFit; no instala automáticamente ODS, Magnitude ni modelos.

Si ./install.sh se queja de que falta LLMFit, vuelve al paso 0, instálalo y reintenta.

Si ya tienes el repositorio:

cd LEONES
git pull --ff-only origin main
./install.sh
./leones
2 · Qué vas a encontrar

La interfaz es una terminal guiada

RC2 no abre una aplicación gráfica: muestra un wizard ASCII en la terminal. La primera pregunta es el idioma (Español / English / 中文). A partir de ahí solo se muestra el idioma elegido.

ELIGE EL IDIOMA / CHOOSE LANGUAGE / 选择语言
┌──────────────────────────────────────────┐
│  [1] Español                             │
│  [2] English                             │
│  [3] 中文                                 │
└──────────────────────────────────────────┘
LEONES>

Después verás el encabezado de LEONES, mensajes de estado y, cuando llega una decisión, una caja de opciones numeradas.

La línea LEONES> es el punto de entrada para tus decisiones. No uses flechas, ratón ni letras salvo que una pantalla concreta las indique: en el wizard actual las opciones se seleccionan escribiendo el número y pulsando Enter.

3 · Teclas

Qué pulsar en cada momento

Idioma

Primera pantalla: elige 1, 2 o 3 y pulsa Enter.

Elegir modelo

Escribe 1, 2, 3… según el candidato mostrado y pulsa Enter.

Elegir stack

Cada opción incluye una descripción breve (ODS = stack local de inferencia; Magnitude = agente/asistente local). Elige el número y pulsa Enter.

Autorizar instalación

En la pantalla de consentimiento, elige la opción numerada de Autorizar y pulsa Enter, o elige Cancelar para salir sin instalar.

Opción inválida

Si introduces algo que no corresponde a una opción, LEONES lo indica y vuelve a mostrar el prompt. No se ejecuta una decisión accidental.

4 · Tus decisiones

Dónde debes tomar decisiones

01

HARDWARE

Observa el hardware detectado. No tienes que introducirlo si la detección funciona. Si algo aparece como desconocido, no lo inventes.

02

MODELO

Compara modelo, fit, requisitos y procedencia. Las cifras con ESTIMATED son orientativas. Aquí decides qué modelo quieres probar.

03

STACK

ODS: stack local de inferencia (modelos, UI y servicios en tu máquina). Magnitude: agente/asistente local orientado a tareas con el modelo elegido. La opción del menú ya incluye esa descripción.

04

INSTALACIÓN

Antes de producir cambios en el equipo aparece el consentimiento. Aquí decides si autorizas la instalación. Puedes cancelar.

05

RUNTIME

Tras verificar el stack, LEONES resuelve el runtime del modelo (Ollama o llama.cpp). Sin artefacto disponible, A01 se bloquea: no se inventa MEASURED.

No todas las pantallas son decisiones

       ↓

       ↓
[ TÚ AUTORIZAS / CANCELAS INSTALACIÓN ]
       ↓
INSTALAR → VERIFICAR
       ↓
RESOLVER RUNTIME → PREFLIGHT
       ↓
[ CONSENTIMIENTO DE BENCHMARK ]
       ↓
SI SÍ → HANDOFF RC1 → MEDICIÓN → EVIDENCIA
SI NO → FIN

La instalación y el benchmark son decisiones diferentes. Una instalación correcta no implica que el benchmark vaya a ejecutarse.

6 · Regla de oro

No confundas lo que ves

ESTIMATED

Estimación de una fuente como LLMFit. Sirve para orientar la elección.

INSTALLED

El stack ha sido instalado o está en proceso. Todavía hay que verificarlo.

VERIFIED

Los health checks de la integración han confirmado que el stack está preparado.

MEASURED

Existe una ejecución real registrada sobre el equipo y el protocolo correspondientes.

ESTIMATED ≠ MEASURED. Una cifra que aparezca antes de ejecutar el benchmark no es el resultado de tu máquina.
7 · Si algo falla

No fuerces el recorrido

Si LLMFit no está disponible, si una opción no puede determinarse, si la instalación falla o si la verificación no pasa, el flujo debe detenerse o marcarse como bloqueado. Conserva el mensaje original.

Etapa: PREFLIGHT | INSTALL | VERIFY | RESOLVE | BENCHMARK | EVIDENCE
Comando:
Error original:
Resultado esperado:
Resultado obtenido:
execution_id (si existe):

Un fallo reproducible también es información útil para la beta.
