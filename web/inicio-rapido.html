Arrancar LEONES

RC3 cerrada. RC4: intención obligatoria, evidencia HF/AA, intersección FitLLM opcional, inventario, cadena MEASURED opt-in.

0 · Qué es canónico

RC4 define la recomendación y el orquestador post-recomendación. RC3 permanece cerrada. FitLLM no es dependencia de arranque.

Regla: sin USER_INTENT[] no hay recomendación. ESTIMATED ≠ MEASURED. No uses literales como <modelo>: pon el id exacto de ollama list.

1 · Requisitos

  • Python 3 y Git.
  • No hace falta FitLLM para arrancar LEONES.
  • Hermes y OMH son opcionales; no seleccionan modelo en RC4.
  • Para intersección real: CLI llmfit. Para tests: pytest (pip install --user pytest).

2 · Arranque

git clone https://github.com/robertosantosx2/LEONES.git
cd LEONES
git checkout rc4-fitllm-recommender
./leones
./leones --inventory
./leones --rc2

3 · Preflight e inventario

python3 scripts/rc4_release_gate.py
python3 scripts/rc4_component_inventory.py
python3 scripts/rc4_resource_preflight.py --path .
python3 scripts/rc4_ubuntu_preflight.py \
  --purpose programming --purpose reasoning \
  --out results/physical-rc4-$(date +%Y%m%d)/ubuntu-preflight.json

insufficient con menos de tres coincidencias es correcto.

4 · Cadena MEASURED (opt-in)

# plan sin ejecutar → measured=false
python3 scripts/rc4_measured_chain.py --model-id demo --stack none --json

# E2E: model_id REAL de ollama list (ejemplo Aspire)
ollama list
python3 scripts/rc4_fitllm_recommend.py --purpose programming --json > /tmp/rec.json
python3 scripts/rc4_measured_chain.py \
  --recommendation /tmp/rec.json \
  --model-id qwen2.5:0.5b-instruct-q4_K_M \
  --stack none \
  --execute --authorize-execution --authorize-measurement \
  --out results/physical-rc4-measured/chain.json

Sin --execute y doble autorización no hay MEASURED.
