Primer flujo autónomo de LEONES

LEONES ya dispone de un orquestador fino que conecta las piezas básicas sin convertirlas en un componente monolítico.

Flujo

Petición
   ↓
Leones Atlas
   ↓
Leones Router
   ↓
Decision
   ↓
Model Preparation
   ↓
Runtime
   ↓
respuesta

Uso

python -m leones.auto_run --atlas leones_atlas.sqlite \
  "Write a Python function that adds two numbers"

Límite intencionado

Esta primera versión solo usa modelos ya registrados y accesibles localmente. No descarga ni modifica modelos. Primero demostramos una ruta autónoma pequeña y verificable.

Próxima evolución

La decisión del Router incorporará progresivamente hardware, RAM/VRAM, cuantización, contexto, latencia, benchmarks y capacidades. Cada criterio tendrá su propia documentación y evidencia.
