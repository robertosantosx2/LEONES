Leones Router

El componente que transforma una tarea en una decisión explicable sobre qué modelo y backend utilizar.

Primera regla

  1. identificar una capacidad aproximada;
  2. recorrer candidatos;
  3. escoger el primero compatible;
  4. mantener su backend declarado.

Capacidades iniciales

coding · reasoning · general

Ejemplo

Petición: "escribe una función Python"
        ↓
capacidad: coding
        ↓
modelo compatible
        ↓
backend: llama.cpp

Principio

El Router no utiliza una puntuación opaca. Cada criterio debe poder explicarse y documentarse. Más adelante incorporará hardware, RAM, cuantización, contexto, latencia y benchmarks.
