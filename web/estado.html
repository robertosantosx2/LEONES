Runtime del host

Docker y Podman se detectan sin suposiciones

Docker

RC2 acepta Docker accesible directamente o mediante sudo. Rootful no es un error. Rootless se registra como una propiedad observada, no como un requisito artificial.

Podman

En Fedora/RHEL-family, Podman puede ser el runtime disponible. LEONES lo detecta y registra su estado, pero no lo convierte por inferencia en una instalación ODS válida.

Compatibilidad

Runtime disponible → acceso funcional → Compose/interfaz compatible → señal específica de ODS. Cada estado tiene su propio gate.

Regla: que Docker o Podman funcionen demuestra capacidad del host; no demuestra que ODS esté instalado ni verificado.

Gates RC2

Ningún paso se satisface por inferencia silenciosa

Hardware / modelo

HARDWARE_READY → MODEL_SELECTED: LLMFit orienta candidatos; la elección final es humana.

Instalación

CONSENT_REQUIRED → INSTALLING → verificación física. Solo una señal de instalación real permite continuar.

Benchmark

BENCHMARK_CONSENT_REQUIRED → EXECUTION_AUTHORIZED. Instalar no autoriza A01.

Evidencia

Solo una ejecución válida produce medición. Un fallo no se publica como resultado válido.

ODS / Magnitude

Elección informada

RC2 presenta capacidades declaradas antes de pedir la elección. No crea un scoring paralelo que sustituya las fuentes especializadas ni convierte sus estimaciones en mediciones LEONES.

ODS

Integración de stack local. La preparación y verificación de LEONES no sustituyen al instalador canónico de ODS.

Magnitude

Integración orientada a agente/asistente local. Preparación y ejecución permanecen separadas de la medición propia de LEONES.

Regla

Medir antes de afirmar

estimated, reported, observed, configured y measured mantienen fronteras distintas. Lo desconocido permanece desconocido.
