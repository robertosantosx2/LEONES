Ideas fundamentales

Un agente no existe para producir tokens: existe para completar objetivos. LOAS separa inferencia de Agentic y mide tareas reales con LOTB.

CABE = puede ejecutarse razonablemente. RULA = ha sido ejecutada y medida.

LOTB: B01 memoria/localidad · B02 archivos · B03 multietapa · B04 recuperación ante fallo · B05 coding local.

Historia y decisiones · README

Buddy: conocimiento controlado

Buddy se utiliza como capa de conocimiento y contexto controlados: qué sabe el agente, qué documentos puede utilizar, qué información conserva y cómo recuperarla durante una tarea. No es el modelo de inferencia.

Objetivo→Buddy
conocimiento + contexto→Harness / agente→Modelo→Herramientas / resultado

La ventaja es separar lo que el sistema sabe de la pieza que genera los tokens.

El conocimiento sobrevive al cambio de pila

Podemos cambiar CPU, GPU, RAM, máquina, modelo, cuantización, backend o harness sin reconstruir el conocimiento controlado.

Hoy
i5 + 16 GB + modelo A + backend A
Mañana
i7 + 64 GB + GPU + modelo B + backend B
Permanece
Conocimiento, estructura, documentos, criterios y memoria controlada.

metaLOAS registra por separado hardware, modelo, backend, harness y resultados para poder comparar las mismas tareas aunque cambie la plataforma.
