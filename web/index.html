El proyecto

LEONES mide sistemas, no solo modelos.

Objetivo

Encontrar qué combinación de hardware, sistema operativo, runtime, backend, modelo, cuantización, harness, herramientas y conocimiento permite completar tareas agentic localmente.

Un agente existe para completar objetivos, no simplemente para producir tokens.

Hardware objetivo

8 · 16 · 32 · 64 GB RAM
Intel i5/i7 o equivalentes
Con o sin GPU

Umbral

10 tok/s
