LEONES RC3 · ARQUITECTURA FIJADA01

Descubrir antes de medir

RC3 simplifica el bootstrap: Hermes descubre el equipo y realiza el fit inicial; Oh My Hermes organiza la operación; el usuario elige el camino; LEONES verifica, mide y conserva la evidencia.

01

DESCUBRIR

Hermes realiza el discovery inicial de hardware, backend y envelope de memoria y propone configuraciones compatibles.

02

OPERAR

Oh My Hermes aporta routing, workflows, handoffs y gates operativos sobre Hermes.

03

NORMALIZAR

LEONES captura el resultado como hardware-profile.v1 y construye un conjunto de candidatos trazable.

04

ELEGIR

La persona elige modelo/configuración y después exactamente un stack: Magnitude u ODS.

05

PREPARAR

El camino elegido instala, configura o prepara mediante sus interfaces canónicas, sin duplicar runtimes.

06

VERIFICAR

LEONES comprueba físicamente qué hardware, runtime, stack y modelo quedaron realmente disponibles.

07

MEDIR

Las tareas autorizadas se ejecutan sobre el equipo real bajo el protocolo LEONES.

08

EVIDENCIAR

Se conserva ejecución, modelo, configuración, hardware, protocolo y resultados para producir una recomendación reproducible.

Stack de ejecución04

Magnitude u ODS: elección explícita

RC3 no obliga a un segundo selector de modelos. Tras Hermes y la normalización LEONES, el usuario elige el stack que quiere utilizar.

MAGNITUDE

Perfilado y tuning

Camino orientado a perfilado, estimación, optimización y ejecución. LEONES verifica y mide el resultado real.

ODS

Instalación y stack

Camino orientado a desplegar el stack local mediante sus interfaces canónicas. LEONES verifica el resultado.

FITLLM / LLMFIT

Fuera de RC3

Queda desacoplado: no se instala, no se invoca y no decide. Se conserva como posible proveedor externo futuro.

ESTIMATED ≠ MEASURED. Las estimaciones externas nunca son por sí solas evidencia física LEONES.
