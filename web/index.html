LEONES RC4 · RECOMENDACIÓN EVIDENCE-BACKED01

Descubrir antes de medir

RC4 exige USER_INTENT[] antes de proponer. LEONES construye un feed HF + Artificial Analysis (≤100); LLMFit se consulta con su CLI real; solo la intersección respaldada se ofrece como ESTIMATED. Hermes/OMH no seleccionan modelo.

01

INTENTAR

El usuario declara para qué quiere la IA (USER_INTENT[], múltiple). Sin intención no hay recomendación.

02

DESCUBRIR

LEONES observa el hardware real (hardware-profile.v1) y prepara el feed de evidencia HF + Artificial Analysis.

03

INTERSECAR

LLMFit (opcional) propone desde su catálogo; LEONES limita a la intersección con el feed. Hasta 3 ESTIMATED o insufficient.

04

ELEGIR

La persona elige modelo/configuración y después exactamente un stack: Magnitude u ODS.

05

PREPARAR

El camino elegido instala, configura o prepara mediante sus interfaces canónicas, sin duplicar runtimes.

06

VERIFICAR

LEONES comprueba físicamente qué hardware, runtime, stack y modelo quedaron realmente disponibles.

07

MEDIR

Las tareas autorizadas se ejecutan sobre el equipo real bajo el protocolo LEONES.

08

EVIDENCIAR

Se conserva ejecución, modelo, configuración, hardware, protocolo y resultados para producir una recomendación reproducible.
