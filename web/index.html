El proyecto

La idea en una pantalla

desarrollo activo

No es solo un benchmark de modelos

LEONES estudia la combinación de hardware + sistema operativo + runtime + backend + modelo + harness + skills + conocimiento necesaria para completar tareas agentic localmente.

Un agente no existe para producir tokens; existe para completar objetivos.

Hardware objetivo

8 · 16 · 32 · 64 GB RAM
Intel i5/i7 o equivalentes
Con o sin GPU

Umbral

10 tok/s

Buddy

Conocimiento controlado que sobrevive al cambio de pila

OBJETIVO → BUDDY → HARNESS / AGENTE → MODELO / BACKEND → RESULTADO

Qué aporta

Buddy separa el conocimiento, contexto y memoria controlada de la pieza que genera tokens.

Por qué importa

Podemos cambiar CPU, GPU, sistema operativo, backend, modelo o harness sin reconstruir el conocimiento acumulado.
