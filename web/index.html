Stack de ejecución03

ODS y Magnitude: no son solo fuentes

LEONES los trata como referencias y, cuando procede, como opciones reales de ejecución. Cada uno aporta capacidades distintas y la elección depende de la necesidad, el hardware y la evidencia disponible.

ODS · OSMANTIC DEPLOYMENT SYSTEM

Un servidor AI local completo

ODS instala y conecta un stack local alrededor de la inferencia: modelos locales, interfaz web tipo ChatGPT, dashboard de control y gestión, detección de hardware y selección de modelo, voz, agentes, workflows, RAG, búsqueda, generación de imágenes, privacidad, observabilidad y herramientas de desarrollo.

Capacidades: Open WebUI; Whisper para transcripción; Kokoro para texto a voz; Qdrant + embeddings para RAG; API compatibles con OpenAI; n8n para automatización; agentes; Privacy Shield para protección de PII; ComfyUI para generación de imágenes; SearXNG y otras opciones de búsqueda; OpenCode; Memory Shepherd; métricas, salud de servicios, gestión de modelos, extensiones y herramientas de diagnóstico.

Infraestructura: instalación automatizada, autodetección de GPU y memoria, selección determinista de modelo según hardware, overlays de aceleración, extensiones modulares y soporte multi-GPU en los caminos compatibles.

En LEONES: ODS es especialmente relevante cuando el objetivo es desplegar una plataforma local completa alrededor del LLM, no solamente ejecutar una inferencia.

MAGNITUDE · LOCAL CODING AGENT

Agente de coding + motor de inferencia local

Magnitude combina un agente de programación con un motor de inferencia local construido en Rust sobre llama.cpp. Perfila el hardware, recomienda modelos ejecutables y gestiona configuración e inferencia orientada al trabajo agentivo.

Capacidades: perfilado de hardware; modos Balanced, Best Quality, Fastest y Lightweight; descarga y configuración de modelos; cálculo previo de memoria; configuraciones verificadas; ajuste de aceleración, placement y batching; reutilización de caché y prefill; cambio de modelos; ventanas de contexto consistentes; agentes paralelos; inspección y edición de archivos; ejecución de comandos; trabajo con imágenes; sesiones largas y delegación a otros agentes.

En LEONES: Magnitude es especialmente relevante cuando la pregunta es qué modelo y configuración permiten completar trabajo de desarrollo real de forma local, no solo qué modelo cabe en memoria.

Regla de evidencia: las capacidades declaradas por ODS o Magnitude sirven para orientar y seleccionar; una medición de LEONES en hardware real sigue siendo una medición propia. ESTIMATED ≠ MEASURED.

Decidir con evidencia

Necesidad → Hardware observado → LLMFit → candidatos → elección humana → ODS / Magnitude → instalación → medición → evidencia.

La documentación, la prospección y la aplicación forman un ciclo continuo: observar, estructurar, decidir, autorizar, ejecutar, medir y aprender.
