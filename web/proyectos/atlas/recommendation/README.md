# Recommendation Engine

Capa de recomendación del Open LLM Atlas integrada en LEONES.

Evalúa modelo, variante, runtime, hardware, workload y restricciones.

Orden inicial: viabilidad técnica → soporte de carga → compatibilidad → rendimiento observado → calidad/capacidades → preferencias → explicación.

La apertura Barahona permanece como dimensión independiente.
