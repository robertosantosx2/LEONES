# Open LLM Atlas

Subproyecto de LEONES para catalogar modelos LLM abiertos/open-weight y alimentar el recomendador de IA local.

Principio central: **modelo × variante × runtime × hardware × workload × restricciones**.

La clasificación Barahona permanece independiente de los scores de rendimiento/calidad. MSA se usa como fuente de observaciones empíricas.

## Integración

El Atlas funciona como subproyecto de datos/conocimiento para las páginas y herramientas de recomendación de LEONES. Las prospecciones diarias pueden alimentar nuevas observaciones y cambios de modelos, runtimes y hardware.

Estado: integración inicial.
