LEONES · Proyecto

Local Ecosystem of Open Neural Expert Systems.

VISIÓN

Conseguir IA local realmente útil en hardware de consumo

LEONES estudia la combinación de hardware, sistema operativo, runtime, backend, modelo, harness, skills y conocimiento necesaria para completar objetivos agentic localmente.

Un agente no existe para producir tokens; existe para completar objetivos.

Qué problema resuelve

Demasiadas piezas

Modelo, cuantización, backend, runtime y agente cambian continuamente. LEONES organiza esas decisiones.

Hardware real

El proyecto parte de máquinas de consumo y de evidencia reproducible, no de configuraciones ideales.

Decisiones explicables

Atlas conserva evidencia y Router transforma esa información en recomendaciones.

Aprendizaje colectivo

La Manada permite agregar mediciones voluntarias y mejorar futuras recomendaciones.

Mapa mental

NECESIDAD → TASK INTELLIGENCE → ATLAS + HARDWARE → ROUTER → MODELO + RUNTIME + AGENTE → EVALUACIÓN → MANADA

La evidencia vuelve al sistema para producir mejores recomendaciones.
