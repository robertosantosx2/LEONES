LEONES · Proyectos

Un ecosistema para estudiar, probar y recomendar IA local con hardware real, evidencia reproducible y una separación clara entre web e infraestructura.

Visión

IA local útil, no solo modelos ejecutándose

LEONES estudia la combinación de hardware, sistema operativo, runtime, backend, modelo, harness, skills y conocimiento necesaria para completar objetivos agentic localmente.

Un agente no existe para producir tokens; existe para completar objetivos.

Cómo se organiza el proyecto

Atlas

Base estructurada de modelos, familias, organizaciones, benchmarks, hardware y evidencia. Su función es conservar conocimiento consultable.

Router

Capa de decisión que relaciona necesidad, hardware, modelo y runtime para encontrar una combinación viable y explicar sus límites.

Evaluación

Metodologías y pruebas que permiten distinguir una afirmación de una medición reproducible.

Manada

Capa para agregar mediciones voluntarias y convertir experiencia real en nueva evidencia para el ecosistema.

Scripts locales

La herramienta se separa de la infraestructura

Los scripts locales no son una versión descargable de toda la infraestructura de LEONES. Son herramientas pequeñas y autónomas que el usuario puede ejecutar en su propio equipo para probar su LLM con su hardware y su runtime.

Principio arquitectónico: la web es el escaparate; los scripts son herramientas locales autónomas.
Web LEONES → Documentación ≠ Scripts locales → LLM + runtime del usuario

LLM Smoke Test

El primer producto local es scripts/local/llm-smoke-test. Su misión es comprobar que un runtime local puede ejecutar un modelo y producir un resultado estructurado sin depender de Atlas, de la web ni de la infraestructura de LEONES.

Contrato común

RESULT_SCHEMA v0.1 define la estructura de los resultados para que los adaptadores puedan compararse sin cambiar el significado de las métricas.

Runtimes

La primera ola prioriza llama.cpp y Ollama. Después se contemplan Transformers, vLLM y MLX.

Medición honesta

TTFT, tiempo de generación, tokens y memoria solo se publican cuando pueden medirse de forma fiable. Lo desconocido permanece como null.

Aislamiento

No se descargan modelos silenciosamente, no se requieren credenciales y no se envían resultados a LEONES por defecto.

Mapa del ecosistema

Necesidad → Task Intelligence → Atlas + Hardware → Router → Modelo + Runtime + Agente → Evaluación → Manada

La evidencia vuelve al sistema para mejorar las recomendaciones. La herramienta local puede funcionar aunque el resto del ecosistema no esté instalado en el equipo del usuario.
