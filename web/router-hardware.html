Router + Hardware Intelligence

Transparencia total: LEONES no afirmará que un modelo cabe en un equipo cuando no disponga del dato necesario para demostrarlo.

Estado actual

El Router ya dispone de una frontera explícita para hardware y conoce la RAM disponible. Sin embargo, los candidatos actuales todavía no contienen requisitos mínimos de RAM, por lo que el filtro no elimina ningún modelo.

Por qué no inventamos datos

Sería fácil asignar consumos estimados y aparentar que el Router es inteligente. No lo hacemos. Primero incorporaremos requisitos con fuente y estado de evidencia en Leones Atlas.

Objetivo

RAM disponible
      ≥
RAM requerida por modelo/cuantización
      ↓
modelo ejecutable

Próximos datos

RAM · VRAM · contexto · backend · cuantización · requisitos específicos del runtime. Cada criterio tendrá evidencia propia.
