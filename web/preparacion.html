Model Preparation

Una barrera pequeña y verificable entre un archivo local y el Runtime.

Comprueba

  • existencia del archivo;
  • formato conocido;
  • SHA-256 cuando se proporciona.

Formatos iniciales

GGUF · safetensors · bin · onnx

No hace

No descarga, convierte, cuantiza ni ejecuta. Cada una de esas tareas tendrá su propia pieza si LEONES las necesita.

Flujo

fuente → descarga → preparación → Runtime

Uso

python -m leones.model_prepare models/model.gguf --sha256 <64-hex>
