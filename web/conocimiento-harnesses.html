Harnesses

Investigación de harnesses OSS filtrados por OSI, organizados por funcionalidad y compatibilidad. Incluye el Selector Harness V1.2; su lista de seis candidatos es una preselección, no una declaración de seis instalaciones realizadas.

Arquitectura

CASO DE USO → HARDWARE / OS → RUNTIME → OPTIMIZACIÓN → CAPACIDAD DEL HARNESS → OSI → COMPATIBILIDAD ODS / MAGNITUDE → PREFLIGHT → SELECCIÓN → INSTALACIÓN / ACTIVACIÓN → SMOKE TEST

Compatibilidad e instalación son propiedades distintas. DIRECT_INSTALL exige una ruta reproducible para la plataforma objetivo. CONSUMER_COMPATIBLE solo significa que el harness puede consumir un runtime/API compatible.

Familias

Selector Harness V1.2

Seis candidatos de referencia. El gate OSI se aplica al núcleo del proyecto. La compatibilidad declarada con ODS/Magnitude se mantiene separada de la instalación real.

Estado: conocimiento y diseño preparados. La instalación concreta requiere preflight sobre plataforma, dependencias, puertos, runtime y recursos; después debe pasar arranque/smoke test. La medición LEONES permanece en not_measured hasta ejecutar.
