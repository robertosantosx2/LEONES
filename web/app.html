Recorrido operativo01

Una sola ruta, con barreras explícitas

01

IDIOMA

El usuario elige una vez entre Español, English o 中文. Durante la sesión solo se muestra el idioma elegido.

02

HARDWARE + LLMFIT

Se observa el equipo real y LLMFit aporta el perfilado y los candidatos. Sus resultados son ESTIMATED.

03

MODELO

La persona elige qué modelo quiere probar. La recomendación no sustituye la decisión humana.

04

ODS / MAGNITUDE

Antes de elegir stack se presentan sus capacidades respaldadas por contrato o evidencia.

05

CONSENTIMIENTO

Elegir stack no instala nada. El consentimiento de instalación es independiente del consentimiento de benchmark.

06

INSTALAR

Se muestra el comando del instalador canónico y se puede instalar ahora o dejarlo para más tarde.

07

VERIFICACIÓN FÍSICA

LEONES observa el host y exige real_installation: true. Un exit 0 del instalador por sí solo no equivale a PASS.

08

A01

El benchmark canónico es LEONES-Agentic / A01. Antes de ejecutarlo se explica qué se medirá y se solicita consentimiento explícito.

09

RC1 → EVIDENCIA

Con autorización se hace handoff al runner RC1. Si Ollama no está disponible, el benchmark queda bloqueado: nunca se inventa una medición.

IDIOMA → HARDWARE/LLMFIT → MODELO → ODS/MAGNITUDE
        → CONSENTIMIENTO INSTALAR → INSTALAR → VERIFICAR
        → CONSENTIMIENTO A01 → RC1 → MEDIR → EVIDENCIA

ODS / Magnitude03

¿Qué aporta cada stack?

ODS

Plataforma AI local

Stack local de inferencia con interfaz y servicios, conocimiento/RAG/search, voz, agentes/workflows, imágenes, privacidad y observabilidad, según la instalación y versión seleccionadas.

LEONES: prepara y verifica; el adaptador no instala ODS por sí mismo.

MAGNITUDE

Agente de coding local

Integración orientada a agente/asistente local: perfilado, recomendación, configuración y ejecución según la instalación y versión seleccionadas.

LEONES: prepara metadatos y reutiliza los contratos comunes de benchmark/evidencia.

Reglas de LEONES04

Qué significa cada estado

ESTIMATED

Orientación procedente de LLMFit u otras fuentes. Sirve para seleccionar y priorizar.

MEASURED

Solo tras una ejecución real registrada por el camino de runtime/evidencia correspondiente.

CONSENT

Instalar ≠ verificar ≠ autorizar benchmark. Cada operación tiene su propia barrera.

UNKNOWN

Si un dato no puede comprobarse, permanece desconocido; no se rellena por conveniencia.
