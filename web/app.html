ASISTENTE LEONES

Empieza por tu necesidad, no por un script

LEONES te lleva por el camino mínimo. Cada paso responde una pregunta y produce un resultado útil. No tienes que ejecutar todo el pipeline.

🖥️ Quiero saber qué puede hacer mi PC

Primero conocer el hardware. El siguiente paso será medir solo si tiene sentido.

🤖 Quiero probar un modelo

Identificar modelo → inferencia → decidir si merece pruebas agentivas.

🧠 Quiero saber si puedo usar un agente

Hardware → runtime → LOTB → evidencia de tareas reales.

🦁 Quiero formar parte de la Manada

Medir → revisar privacidad → publicar → ayudar a mejorar futuras recomendaciones.

Tu siguiente paso

Elige una necesidad arriba. LEONES seleccionará el paso mínimo necesario.

0% del recorrido

Selecciona un camino para generar el comando local.

Por qué compartir

Un resultado técnico anónimo de tu PC aumenta la evidencia sobre hardware real. Con suficientes contribuciones, LEONES podrá distinguir mejor qué modelos, runtimes y combinaciones funcionan de verdad y hacer recomendaciones futuras más precisas.

Regla de confianza

Local → revisar → publicar → agregar → aprender. Publicar es voluntario. La aplicación nunca ejecuta comandos en tu ordenador desde GitHub Pages.

🦁 MANADA_LEONES

Compartir es ayudar a que LEONES recomiende mejor

Tu máquina puede ser el dato que mañana cambie una recomendación. Una medición aislada aporta poco; miles de mediciones de hardware real permiten encontrar patrones.

TU PC
→

→

MEJOR ROUTER

Se comparte

  • Hardware técnico necesario.
  • Modelo, formato y quantización.
  • Backend y versiones relevantes.
  • Mediciones y LOTB.
  • Estado de evidencia.

No se comparte

  • Nombres o identidad personal.
  • Rutas personales/home.
  • Seriales, UUID, MAC/IP.
  • Credenciales, tokens o secretos.
  • Archivos personales.
Contribución voluntaria. La finalidad es conocimiento colectivo, no vigilancia. Antes de publicar, revisa el resultado y elimina cualquier dato que no deba salir de tu máquina.

📣 Difunde tu contribución

Si autorizas la publicación social, LEONES puede preparar un tweet sin datos personales con el resultado técnico. Tú revisas el texto y decides si publicarlo.

Autorización explícita. Marcar esta opción no publica nada automáticamente: abre X con un borrador para que puedas revisarlo antes de publicar.

El enlace se guarda solo en este navegador para que puedas volver a él.

¡Ayúdanos a mover la Manada! Si publicas el resultado, te invitamos a retuitearlo y compartirlo. Cuantas más mediciones reales lleguen a la comunidad, mejor podrá LEONES recomendar qué ejecutar en cada máquina.
