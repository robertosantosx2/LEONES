Del diagnóstico a la evidencia

La aplicación web explica y guía el recorrido. Las operaciones sobre tu equipo solo ocurren cuando el flujo y los consentimientos correspondientes las autorizan.

Recorrido operativo01

Una sola ruta, sin atajos ocultos

01

HARDWARE

LEONES observa el equipo real: CPU, RAM, aceleradores, sistema y capacidades disponibles.

02

LLMFIT

Se utiliza la inteligencia especializada disponible para perfilar la relación entre hardware y modelos candidatos.

03

CANDIDATOS

Se construye un conjunto razonado de opciones, conservando lo que se conoce y marcando como desconocido lo que no puede afirmarse.

04

ELECCIÓN

La persona decide qué modelo quiere probar. LEONES no convierte una estimación en una decisión silenciosa.

05

ODS / MAGNITUDE

Se compara el stack de ejecución adecuado a la necesidad: plataforma AI local completa con ODS o agente de coding + inferencia local con Magnitude, entre las opciones compatibles.

06

INSTALACIÓN

Se presenta el plan y se solicita consentimiento específico. Instalar no autoriza a ejecutar un benchmark.

07

VERIFICACIÓN

El stack debe comprobarse en el equipo real antes de quedar listo para benchmark.

08

BENCHMARK

Un segundo consentimiento autoriza la ejecución y el handoff al runner RC1 canónico.

09

EVIDENCIA

La ejecución produce medición real y evidencia reproducible. ESTIMATED ≠ MEASURED.

ODS / Magnitude02

¿Qué aporta cada stack?

ODS

Plataforma AI local

Inferencia: modelos locales y selección basada en hardware.

Interfaz y operación: Open WebUI, dashboard, gestión de servicios, modelos y estado de GPU.

Conocimiento: RAG con Qdrant + embeddings, búsqueda local con SearXNG y opciones de investigación.

Voz: Whisper para STT y Kokoro para TTS, con soporte para flujos de voz.

Agentes y automatización: agentes, n8n/workflows y herramientas para automatizar tareas.

Creatividad: generación de imágenes mediante ComfyUI.

Privacidad y operaciones: Privacy Shield, gestión de secretos/auth, observabilidad, diagnósticos, métricas y Token Spy.

Desarrollo: OpenCode, sistema de extensiones y Memory Shepherd.

MAGNITUDE

Agente de coding local

Perfilado: analiza el hardware y recomienda modelos con modos Balanced, Best Quality, Fastest y Lightweight.

Inferencia: motor Rust sobre llama.cpp, configuraciones verificadas, cálculo de memoria y ajuste de aceleración, placement y batching.

Rendimiento: expone prefill, reutilización de caché y generación; gestiona carga y cambio de modelos.

Agencia: inspecciona y edita archivos, ejecuta comandos, trabaja con imágenes, mantiene sesiones largas y delega tareas a agentes paralelos.

Local: la inferencia local y el trabajo del agente se realizan en la máquina; su servicio cloud es una opción separada para modelos demasiado grandes para el hardware local.

Reglas de LEONES03

Lo que una recomendación significa

Estimación

Sirve para orientar candidatos y elegir qué merece la pena probar.

Medición

Solo existe cuando el modelo se ejecuta realmente sobre el hardware indicado siguiendo el protocolo.

Consentimiento

La autorización para instalar y la autorización para benchmark son independientes.

Desconocido

Si un dato no puede comprobarse, permanece desconocido; no se rellena por conveniencia.
