LEONES separa conocimiento, capa agentic e inferencia. LOTB mide las capacidades agentic y metaLEONES permite aportar resultados técnicos sin publicar datos personales.

2. El conocimiento sobrevive al cambio de pila

Machine A ──┐
Model A ────┤
Backend A ──┤
Harness A ──┤──► Buddy / conocimiento controlado
             │                 │
             └─────────────────┘
                               │
                               ▼
Machine B + Model B + Backend B + Harness B

La idea central de Buddy es separar el conocimiento y el contexto controlados de las piezas sustituibles de la pila. Cambiar hardware, modelo, backend o harness no debería obligar a perder el conocimiento acumulado.

Un resultado puede ser reproducible sin estar verificado. LEONES no debe confundir publicación, reproducibilidad y verificación.

5. Prospección y recomendaciones

      │
      ▼

      │

LEONES descubre proyectos Open de forma amplia y prioriza los Copyleft. Descubrir un proyecto no significa recomendarlo: debe inspeccionarse, clasificarse y evaluarse.

El objetivo no es maximizar tok/s de forma aislada. LEONES debe indicar qué pieza de la pila merece cambiarse para mejorar la experiencia real.

7. Frontera de privacidad

LOCAL MACHINE
     │
     ├── technical facts ───────► metaLEONES
     │
     └── personal information ──X  NEVER PUBLISH

Los informes describen el experimento y la configuración técnica, no identifican al operador.
