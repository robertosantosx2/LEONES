LEONES estudia la combinación de hardware, sistema operativo, backend, modelo, harness, conocimiento y herramientas necesaria para completar objetivos agentivos localmente.

La pila completa

HARDWARE
   ↓
SISTEMA OPERATIVO
   ↓
RUNTIME / DRIVERS
   ↓
BACKEND DE INFERENCIA
   ↓
MODELO + CUANTIZACIÓN
   ↓
HARNESS / AGENTIC STACK
   ↓
HERRAMIENTAS / SKILLS
   ↓
BUDDY / KNOWLEDGE
   ↓
EVALUACIÓN → RESULTADO

Cada capa es sustituible. La arquitectura debe permitir identificar el cuello de botella sin crear una segunda arquitectura paralela de ejecución.

Selección

Declara modelo, cuantización, runtime, restricciones y autorización. No declara rendimiento medido.

Runtime

Ejecuta la configuración autorizada sobre el host real.

Benchmark

Representa la tarea que queremos completar, no solo una cifra sintética.

Evidencia

Conserva procedencia, timestamps, execution_id y métricas sin elevar estados por inferencia.

Bucle de mejora

RESULTADO → ANÁLISIS DE PILA → CUELLO DE BOTELLA
                         ↓
               modelo / backend / harness / tools
                         ↓
                    RECOMENDACIÓN
                         ↓
                     RE-EVALUAR

Regla: no optimizar tok/s aisladamente; optimizar la experiencia real al completar tareas.
