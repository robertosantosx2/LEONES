LEONES estudia la combinación de hardware, sistema operativo, backend, modelo, harness, conocimiento y herramientas necesaria para completar objetivos agentivos localmente.

La pila completa

HARDWARE
   ↓
SISTEMA OPERATIVO
   ↓
RUNTIME / DRIVERS
   ↓
BACKEND DE INFERENCIA
   ↓
MODELO + CUANTIZACIÓN
   ↓
HARNESS / AGENTIC STACK
   ↓
HERRAMIENTAS / SKILLS
   ↓
BUDDY / KNOWLEDGE
   ↓
Evaluación
   ↓
RESULTADO + UX

Cada capa es sustituible. La arquitectura debe permitir identificar el cuello de botella y cambiar la pieza que produzca mayor mejora.

Evaluación

Evaluación agentiva: no mide solamente tokens por segundo, sino capacidad de completar tareas reales.

Bucle de mejora

RESULTADO → ANÁLISIS DE PILA → CUELLO DE BOTELLA
                         ↓
               modelo / backend / harness / tools
                         ↓
                   RECOMENDACIÓN
                         ↓
                      RE-EVALUAR

Regla: no optimizar tok/s aisladamente; optimizar la experiencia real al completar tareas.

Prospección y evidencia

La prospección descubre diariamente nuevos modelos, runtimes, harnesses, skills y herramientas. Los resultados medidos alimentan la evidencia que posteriormente puede mejorar Atlas y Router.

DESCUBRIR → REVISAR → MEDIR → EVIDENCIA → APRENDER
