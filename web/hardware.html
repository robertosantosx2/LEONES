Hardware Intelligence

El hardware no es una nota al margen: es una entrada fundamental del Leones Router.

Primera versión

  • CPU
  • arquitectura
  • RAM total
  • CPUs lógicas
  • sistema operativo
  • capacidades básicas

Esta versión deliberadamente no intenta medir rendimiento ni detectar exhaustivamente GPU/NPU.

Dos scripts, dos responsabilidades

hardware_report detecta y muestra.

python -m leones.hardware_report

hardware_register detecta y registra en Atlas.

python -m leones.hardware_register --atlas leones_atlas.sqlite

La separación evita crear un script que haga demasiadas cosas.

Próximos probes

GPU/VRAM, NPU, instrucciones CPU, memoria disponible, almacenamiento y microbenchmarks LEONES se incorporarán como componentes independientes.
