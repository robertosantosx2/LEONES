De conocimiento a atlas operativo

La web de LEONES evoluciona desde un compendio documental hacia una interfaz capaz de responder qué puede ejecutar una persona en su hardware, con qué stack y con qué evidencia.

La promesa de la web

CASO DE USO → HARDWARE → RUNTIME → OPTIMIZACIÓN → MODELO → HARNESS → TOOLS / MCP → MEMORIA / RAG → SEGURIDAD → BENCHMARK → MEDICIÓN → RECOMENDACIÓN

Dos niveles de entrada: una respuesta rápida para quien quiere saber qué puede hacer hoy y profundidad documental para quien quiere verificar por qué.

Principios de producto

  1. Valor inmediato sin sacrificar profundidad.
  2. Fuente, Evidencia, Estimación y Medición nunca se mezclan.
  3. La incertidumbre se muestra; no se oculta.
  4. Compatibilidad, instalación, smoke test y benchmark son estados distintos.
  5. La Manada y las mediciones reales son una prioridad de producto.
  6. Las recomendaciones deben explicar su procedencia.
