Validación física

Lo que ya hemos comprobado

🟢 Instalador mínimo

install.sh es ejecutable y no instala automáticamente stacks ni modelos. LLMFit es dependencia dura.

🟢 Terminal interactivo

El lanzador restaura el eco del terminal para que las entradas del operador sean visibles durante el wizard.

🟢 Docker / Compose

Se distingue Docker directo, sudo, rootless y Podman. La máquina de validación observó Docker 29.1.3 y Compose v5.5.0.

🟢 ODS físico

Se observó ODS CLI v2.6.0 y la imagen ods-privacy-shield:latest. Observado no significa medido.

🟢 Cancelación

Cancelar el instalador externo devuelve fallo explícito y no autoriza el benchmark.

🟢 Desinstalación

--leones limpia el estado local preservando checkout y evidencias históricas.

A01 · primera prueba física

Bloquear también es validar

LLMFit seleccionó un candidato GGUF de Hugging Face. Ollama estaba disponible, pero ese identificador no existía como modelo instalado en Ollama. LEONES devolvió benchmark_blocked y no publicó una medición.

Nueva frontera

Resolución explícita modelo → runtime

1 · Candidato

LLMFit proporciona identidad, fit y rendimiento estimado. Se conserva como estimated.

2 · Resolución

LEONES determina el runtime compatible con el formato real del modelo. GGUF puede resolver a llama.cpp; no se convierte en Ollama por defecto.

3 · Preparación

La resolución es declarativa: no descarga ni instala modelos. La preparación requiere su propia autorización.

4 · Verificación

Runtime y artefacto deben estar disponibles antes de abrir A01.

5 · Medición

Solo una ejecución real genera measured y nueva evidencia.

Regla de evidencia

Estimación no es medición

LLMFit orienta; la ejecución real demuestra. Las cifras de fit/tok/s de LLMFit permanecen como estimated. Una evidencia LEONES sólo nace de una ejecución física con el runtime y protocolo correspondientes.

Un beta tester debe producir su propio execution_id, timestamp, métrica y procedencia. Una medición histórica nunca sustituye una ejecución actual.

Instalación

Actividad visible y fallos honestos

Actividad

Las operaciones largas muestran actividad y solo porcentajes que representen fases reales conocidas por LEONES.

Errores

Un fallo de conectividad o del instalador externo conserva el error original y no avanza al benchmark.

Sin duplicados

LEONES no crea otro instalador de ODS, otro instalador de Magnitude ni otro runner RC2.
