Regla de evidencia

Estimación no es medición

LLMFit orienta; la ejecución real demuestra. Las cifras de fit/tok/s de LLMFit se conservan como estimated. Una evidencia de LEONES sólo nace de una ejecución física con el runner/protocolo correspondiente.

Un beta tester debe producir su propio execution_id, timestamp, métrica y procedencia. Una medición histórica no sustituye una ejecución actual.

Instalación

Actividad visible y fallos honestos

Durante operaciones largas

LEONES debe mostrar actividad y, cuando conozca fases reales, un porcentaje que represente esas fases. Nunca debe inventar el progreso interno de un instalador externo.

Si la red falla

Un timeout del instalador externo se registra como fallo de instalación, conservando el error original. No se presenta como instalación exitosa ni se continúa al benchmark.

Sin arquitectura paralela

LEONES no crea otro instalador de ODS, otro instalador de Magnitude ni otro runner RC2. Reutiliza las interfaces y runners canónicos.
