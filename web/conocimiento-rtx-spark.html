¿Qué se predice?

Hipótesis para LEONES

La gran memoria unificada puede ampliar el conjunto de modelos que caben localmente frente a GPUs con VRAM dedicada menor. Pero capacidad de memoria no equivale a rendimiento de inferencia: el selector debe considerar bandwidth, cuantización, runtime, contexto y workload.

Por ello RTX Spark es una señal de hardware para LLMFit/selección, no un score.

¿Qué ha medido LEONES?

Medición LEONES

Pendiente. No se convierte ningún dato del fabricante en tok/s, latencia o puntuación LEONES. Para promover RTX Spark a evidencia física habrá que ejecutar el runtime elegido y registrar hardware, modelo, cuantización, contexto, versión, workload y protocolo.

Lectura técnica para el selector

La arquitectura de memoria unificada hace especialmente importante distinguir tres variables que a menudo se confunden:

Capacidad determina qué modelos pueden residir; ancho de banda condiciona cuánto dato puede alimentar el cálculo; runtime y workload determinan cómo se aprovecha realmente la plataforma.
