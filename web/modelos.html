Model Intelligence

La capa que describe modelos para que Leones Atlas pueda utilizarlos en decisiones posteriores.

Qué registra

  • identidad y revisión
  • familia
  • formato
  • cuantización
  • tamaño
  • capacidades
  • licencia
  • fuente

Qué NO hace

El registro no descarga modelos, no ejecuta inferencia y no verifica automáticamente la licencia. Es una pieza pequeña y explícita.

Flujo

Model Intelligence → Model Store → Leones Atlas
                              ↓
                         Leones Router
                              ↓
                           Runtime

Ejemplo

python -m leones.model_register --atlas leones_atlas.sqlite \
  --id qwen3-8b --family Qwen3 --format GGUF \
  --quant Q4_K_M --size 5.0 --license Apache-2.0
