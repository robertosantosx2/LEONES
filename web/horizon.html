Horizon

Radar de noticias y actividad que recopila fuentes, deduplica, analiza, enriquece y genera briefings.

Ver proyecto oficial en GitHub

Candidato

Por qué interesa a LEONES

Horizon encaja con el ciclo de prospección porque observa múltiples fuentes y puede convertir ruido heterogéneo en información priorizada.

Estado LEONES: candidato para evaluación. Descubrir una herramienta no equivale a recomendarla ni a incorporarla automáticamente al stack.

Flujo

Fuentes→Fetch→Deduplicate→AI analyse/filter→Enrich→Summarize→Deliver

Qué aporta

Fuentes

La documentación del proyecto describe Hacker News, RSS/Atom, Reddit, Telegram, Twitter/X, GitHub y OpenBB.

Salidas

Describe GitHub Pages, email, webhooks, MCP y archivos locales.

Configuración

Permite ajustar fuentes, perfiles de procesamiento, modelos, idiomas y canales de entrega.

Automatización

Está orientado a ejecuciones recurrentes y a generación de briefings.

Qué debe comprobar LEONES antes de adoptarlo

Recursos

Consumo de CPU, RAM y almacenamiento durante una ejecución completa.

Calidad

Deduplicación, filtrado, enriquecimiento y calidad de los resúmenes.

Local

Qué parte puede ejecutarse con modelos y servicios locales y qué dependencias externas necesita.

Integración

Utilidad real de MCP y de sus salidas para el radar y el conocimiento de LEONES.

Puerta de entrada: Prospección → evaluación → evidencia → posible integración.

Licencia
