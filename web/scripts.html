LEONES · Scripts

Herramientas pequeñas, cada una con una responsabilidad clara.

La regla

No se entra en LEONES preguntando qué script ejecutar. Se empieza por una necesidad y el sistema propone la herramienta.

Necesidad Script / herramienta Salida
Perfil de máquina hardware CPU, RAM, GPU, SO
Identidad de modelo model Modelo y formato
Runtime runtime Backends disponibles
Inferencia infer Rendimiento
Tareas agentivas lotb B01–B05
Informe report result.json / report.md
Privacidad privacy Revisión antes de compartir
Publicación publish Paquete voluntario
Estadísticas stats Datos agregados

Cadena típica

hardware → model → runtime → infer → LOTB → report → privacy → publish → stats

Cada paso debe poder ejecutarse y auditarse por separado.
