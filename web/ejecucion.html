Ejecución local

Primer punto en el que LEONES puede pasar de describir un modelo a ejecutarlo realmente.

Herramienta mínima

python -m leones.run_model models/model.gguf "Explica qué es una red neuronal" --max-tokens 128

Flujo

Model Preparation
       ↓
Runtime Check
       ↓
Run Model
       ↓
llama-cli
       ↓
respuesta

Responsabilidad

run_model recibe explícitamente un archivo local y un prompt. No selecciona modelos, no descarga, no cuantiza, no hace fine-tuning y no ejecuta benchmarks.

Por qué empezamos así

Antes de automatizar la selección debemos demostrar una ruta de ejecución mínima y verificable. Después Leones Router podrá decidir qué modelo y runtime utilizar.
