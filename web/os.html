LEONES · Ubuntu / RHEL

Sistemas operativos y ejecución local.

Principio

LEONES no ata la arquitectura a un sistema operativo. Ubuntu y RHEL pueden ofrecer caminos distintos para drivers, runtimes y paquetes, manteniendo el mismo modelo conceptual.

Ubuntu

git clone https://github.com/robertosantosx2/LEONES.git
cd LEONES
python3 --version
python3 scripts/leones.py hardware

La configuración concreta depende del hardware y del backend.

RHEL

git clone https://github.com/robertosantosx2/LEONES.git
cd LEONES
python3 --version
python3 scripts/leones.py hardware

La arquitectura se conserva; cambian paquetes, drivers y detalles de integración.

Qué debe documentarse

Hardware → drivers → runtime → backend → modelo → harness → LOTB. El objetivo es poder reproducir la configuración y explicar qué pieza condiciona el resultado.
