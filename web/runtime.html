Leones Runtime

La capa de ejecución local de LEONES se construye mediante adaptadores pequeños e intercambiables.

Primer paso

runtime_check comprueba si llama-cli está disponible y obtiene su versión.

python -m leones.runtime_check

No instala ni ejecuta

La comprobación no instala llama.cpp, no descarga modelos y no ejecuta inferencia. Solo proporciona al Router una evidencia básica de disponibilidad del runtime.

Flujo

Hardware → Runtime Check → Router → Runtime

Principio

Primero comprobaciones pequeñas. Después ejecución mínima de un modelo ya preparado. La selección, descarga y preparación permanecen fuera de este componente.
