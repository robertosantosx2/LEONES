# Bots de prospección del Atlas

Estos bots son descubridores, no validadores.

- `models.py` — modelos y familias.
- `runtimes.py` — runtimes/inference engines.
- `agents.py` — agentes y frameworks.
- `skills.py` — skills reutilizables.
- `harnesses.py` — harnesses y evaluación.

Todos escriben en `data/discovery/` y aplican la política de licencias de `docs/ATLAS_LICENSE_POLICY.md`.
