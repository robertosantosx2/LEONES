# 🦁 LEONES · Manada

La Manada permite compartir resultados locales de forma voluntaria para mejorar recomendaciones agregadas.

## Flujo v0.1

`resultado local → revisión → privacidad → consentimiento → publicación → agregación`

No se publican rutas locales, IP, MAC, hostname, coordenadas, secretos ni prompts privados.

## Estados

- local: resultado solo en la máquina;
- reviewed: revisado por el usuario;
- publishable: pasó privacidad y consentimiento;
- published: enviado a la Manada;
- aggregated: incorporado a estadísticas agregadas.

La publicación no convierte un resultado en verdad universal: conserva procedencia y estado de evidencia.

## Estado
