# JALÓN 11 — artefactos de operación E2E

Este directorio conserva operaciones E2E generadas durante la validación. Los artefactos declarativos identifican referencias; no convierten una simulación en evidencia física.

Cuando exista una ejecución real, su evidencia debe conservarse en la ruta contractual de runtime y ser referenciada desde la operación E2E.
